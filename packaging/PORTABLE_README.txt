CHARACTER SHEET APP
===================

Portable edition
----------------
1. Extract the complete "Character Sheet App" folder from the ZIP archive.
2. Open "Character Sheet App.exe" inside that folder.
3. Keep the _internal folder beside the executable.

Installed edition
-----------------
If "Character-Sheet-App-Setup.exe" is included, open it and follow the installer.
The setup program is optional and is only produced on a build machine with Inno
Setup installed.  The portable ZIP above is the complete application and does
not require an installer or Python.

Character data
--------------
Characters and preferences are stored for each Windows user under:
  %LOCALAPPDATA%\CharacterSheetApp

Installing an update or uninstalling the application does not delete that folder.
Use File > Save Character As to create shareable character files and backups.
